Privacy

What this site records, and what it never does

This is a personal site. It carries no advertising, no third-party analytics, no marketing pixels and no cross-site tracking — there is no Google Analytics here, no Meta pixel, nothing loading from a company that wants to follow you elsewhere.

It does record some things, because otherwise there is no way to know whether anything works or whether anyone is using it. Here is all of it, specifically.

What Gets Recorded

Three places, nothing else

1 · Page views

When you open a page, it sends: which page, a timestamp, the referring site if you arrived from a link, your screen size, and the first 120 characters of your browser's user-agent (its self-description — browser and operating system).

It also sends a random identifier stored in your browser, so two visits from the same browser can be recognised as the same browser. It is a random string, it is not derived from anything about you, and it is not linked to any name, email or account. Clearing your site data erases it and you become a new visitor.

Your IP address is not included in this.

2 · Song Analyzer requests

The Song Analyzer runs on a machine at home rather than a cloud service. Requests to it are logged in the ordinary way a web server logs requests: IP address, country, which endpoint was called, the response code, the size, how long it took, and the user-agent.

This is the only place an IP address is recorded, it applies only to the analyzer (not to reading pages), and those logs are deleted after 14 days automatically. They exist so that when something breaks — and it does — there is enough information to find out why.

3 · Cloudflare

The site is served through Cloudflare, which keeps its own standard traffic statistics: request counts, rough visitor numbers, countries, cache performance. What I can see there is aggregate only — totals and charts, not individuals.

Songs You Analyze

Because the analyzer keeps a cache

When a song is analyzed, the audio and the resulting analysis — chords, key, tempo, and lyrics if you asked for them — are cached on the server so the next person asking for that song gets an instant answer instead of re-running everything.

That cache is keyed by the song, not by who requested it. There is no record connecting a person to a song they looked up. The cache is also visible to everyone as the Library, so treat an analyzed song as public.

Uploaded files are stored the same way, identified by a hash of their contents. If you would not want a file to sit on someone else's computer or appear in a public library, do not upload it.

The Feedback Form

Whatever you write, plus an email address only if you choose to give one. The email is used to reply and nothing else — it is not added to any list, because there is no list.

Things Kept In Your Browser

Which never reach the server

Several tools remember your settings locally — the synth's patches and preferences, the guide's selected key and scale, trainer high scores, news source choices. This lives in your browser's own storage, stays on your device, and is never sent anywhere.

There are no cookies in the tracking sense. Nothing here is readable by any other website.

What Never Happens

Your data is never sold, rented or traded.

There are no advertisements and no advertising networks.

There is no third-party analytics — no Google Analytics, no Meta pixel, no session recording, nothing watching you on other sites.

Nothing is used to build a profile of you.

No account is required to use anything here, so there is nothing to sign up for and nothing to delete.

Services Involved

Three, and only because the site has to run somewhere. Cloudflare serves the pages and carries traffic to the analyzer. Google Firebase stores the page-view records and feedback messages. The Song Analyzer itself runs on hardware at home, which is why its logs are on a machine rather than a service.

Analyzing a YouTube link means the server fetches that video's audio, so the request reaches YouTube from this server — not from you.

Asking For Removal

Use the feedback form and say what you want removed. Since nothing is tied to an identity, the practical options are: page-view records associated with your browser's random identifier (tell me the identifier, or just clear your site data and it stops existing), and any analyzed song or uploaded file you want taken out of the cache.

Analyzer request logs delete themselves within 14 days regardless.

Changes

If what is collected changes, this page changes with it. The site is open source, so the code doing the collecting can be read directly rather than taken on trust — which is a better guarantee than anything a page like this can promise.
